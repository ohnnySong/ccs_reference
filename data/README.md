# Data Directory

`aggregate/` contains non-identifying statistics for both CCS data populations:

- the complete 1,785-image quality-gate cohort, including 621 NA images;
- the final 954-image gradable development cohort and its fixed 777/177 patient-disjoint split.

Record-level clinical data and source images are controlled artifacts and are not stored in this public repository. See [`../DATA_ACCESS.md`](../DATA_ACCESS.md).
